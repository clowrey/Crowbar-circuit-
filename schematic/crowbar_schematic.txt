===============================================================================
  SIGNAL FLOW SUMMARY
===============================================================================

  1. HV Bus → R1a → R1b → R2+VR1 → GND          (Voltage sensing divider)
  2. Divider midpoint → TL431 REF pin              (Threshold comparison)
  3. V_local → R5 → TL431 Cathode → TL431 Anode   (TL431 bias / switching)
  4. TL431 Cathode → R6 → Q1 Base                  (Drive signal)
  5. Q1 Collector → R7 → SCR Gate                   (Gate current delivery)
  6. SCR fires → shorts HV Bus → Fuse F1 blows     (Protection action)

===============================================================================
  SAFETY FEATURES KEY
===============================================================================

  [F1]   Fuse — disconnects supply after crowbar fires
  [MOV1] MOV — absorbs fast transients before SCR can respond
  [R9+C2] Snubber — dv/dt protection for SCR
  [R8]   Gate shunt — noise immunity
  [ZD3]  Gate zener — overvoltage protection
  [ZD2]  V_EB clamp — protects PNP driver
  [C3]   Noise filter — prevents false TL431 triggering
  [R1a+R1b, R3+R4] Split resistors — voltage derating
  [C1+C4] Supply decoupling — clean gate trigger pulse
  [VR1]  Trimmer — precise threshold calibration
